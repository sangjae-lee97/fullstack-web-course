
# Chapter 08 학습 기록

## 이번 장에서 이해한 개념

- const와 let: 변수 선언과 값 변경의 차이
- typeof: 값의 자료형 확인
- if / else: 조건에 따라 다른 코드 실행
- for: 인덱스를 사용한 반복
- for...of: 배열의 값을 하나씩 꺼내 반복
- Template Literal: 문자열에 변수 값 삽입

## 가장 어려웠던 코드

```javascript
for (let i = 0; i < members.length; i++) {
    console.log(members[i]);
}
```

- i가 0부터 시작하는 이유
- i++로 반복 횟수를 증가시키는 원리
- members[i]로 배열의 값에 접근하는 방법

## LLM에게 질문한 내용

- console.log()의 결과가 웹페이지에 표시되지 않는 이유
- 배열의 인덱스가 0부터 시작하는 원리
- typeof와 console.log()의 차이

## LLM 답변에서 내가 직접 검증한 내용

- Console에서 JavaScript 실행 결과 확인
- members[1]이 두 번째 회원을 반환하는지 확인
- 나이가 20세일 때 성인으로 판별되는지 확인
- ReferenceError 발생 위치와 원인 확인
